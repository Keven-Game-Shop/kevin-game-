# KEVIN GAME STORE — نسخة أولية
## ما الذي يعمل في هذه النسخة؟
- واجهة عربية متجاوبة للموبايل والكمبيوتر.
- أقسام: شحن على الأكونت، شحن بالـ ID، العضويات، الحسابات، العروض.
- اختيار خدمة ثم تجهيز رسالة طلب إلى واتساب.
- ملف manifest وService Worker كبداية لتجربة PWA وتثبيت الموقع.
- لا يوجد تخزين لبيانات العملاء أو كلمات المرور أو بيانات الدفع.
## قبل النشر
1. افتح `app.js` وراجع كل الأسعار. بعض أسعار قسم ID والحسابات/العروض مجرد قيم أولية أو أسعار تحتاج تأكيدًا؛ عدّلها قبل النشر.
2. تأكد أن رقم واتساب `201064836718` هو الرقم الصحيح بصيغة دولية دون +.
3. أضف صورًا أصلية للحسابات المعروضة مع إثبات ملكية وتفاصيل واضحة. لا تضع حسابًا غير متاح للبيع.
4. ارفع الملفات إلى مستودع GitHub، ثم Settings → Pages → Deploy from a branch → اختر `main` و`/ (root)`.
5. افتح رابط GitHub Pages عبر HTTPS من Chrome على الهاتف. من قائمة المتصفح اختر «إضافة إلى الشاشة الرئيسية» أو «تثبيت التطبيق» إذا ظهر الخيار.
## مهم
- GitHub Pages يستضيف واجهة ثابتة فقط؛ لا توجد لوحة إدارة محمية أو قاعدة بيانات أو تحقق تلقائي من الدفع في هذه النسخة.
- طلب واتساب لا يعني أن الدفع تم. راجع التحويل داخل تطبيق البنك/المحفظة نفسه، ولا تعتمد على صورة إيصال فقط.
- لا تطلب كلمة مرور Free Fire أو Facebook/Google من العملاء. بيع وشراء الحسابات قد يخالف شروط اللعبة ويعرّض الأطراف لفقدان الحساب؛ وضّح المخاطر قبل عرض هذه الخدمة.
- الأسعار ليست متصلة بمورد شحن مباشر، لذا يلزم تحديثها يدويًا والتحقق من التوفر قبل التأكيد.
