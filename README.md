# KEVIN GAME STORE — نظام الطلبات
هذه نسخة بداية جاهزة للتركيب على GitHub Pages. تعتمد على Firebase Authentication + Firestore + Cloud Storage.
لا يوجد تكامل دفع تلقائي؛ العميل يحوّل يدويًا ويرفع إيصالًا، والأدمن يتحقق من وصول المال قبل الشحن.
## مهم قبل النشر
1. أنشئ مشروع Firebase من https://console.firebase.google.com/
2. أضف Web App من إعدادات المشروع، وانسخ الإعدادات إلى `firebase-config.js`.
3. فعّل Authentication > Sign-in method > Email/Password.
4. أنشئ مستخدم الأدمن من Authentication > Users. استخدم إيميلًا خاصًا لا تشاركه مع العملاء.
5. أنشئ Firestore Database.
6. أنشئ Storage.
7. في كل من `firestore.rules` و`storage.rules` استبدل `REPLACE_WITH_YOUR_ADMIN_EMAIL` بإيميل الأدمن الحقيقي، ثم انشر القواعد من Firebase Console.
8. ارفع `index.html`, `app.js`, `firebase-config.js`, `admin.html`, `admin.js` إلى جذر مستودع GitHub Pages.
9. افتح `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/admin.html` وسجل الدخول.
## أمان وتشغيل
- إعدادات Firebase العامة ليست كلمة مرور. الحماية الحقيقية هي قواعد Firestore وStorage.
- لا تضع كلمة مرور الأدمن أو مفاتيح خدمة خاصة في ملفات GitHub.
- العملاء لا يستطيعون قراءة طلبات الآخرين؛ الأدمن فقط يستطيع عرض الطلبات والإيصالات.
- الطلب يُسجّل قبل رفع الصورة. لو فشل رفع الصورة بعد إنشاء الطلب، قد يظهر طلب بلا إيصال؛ راجع القائمة وسجّل الطلب يدويًا/تواصل مع العميل.
- قواعد الإيصالات تسمح بإنشاء ملف إيصال فقط وبحجم أقل من 5MB ونوع صورة مدعوم. يجب إضافة حماية ضد إساءة الاستخدام/الطلبات الآلية قبل الاعتماد التجاري الواسع.
- إعدادات وسائل الدفع في `index.html` افتراضية ومبنية على رقم التواصل الحالي؛ راجعها قبل النشر.
- أسعار شحن الحساب والجواهر والعضويات والدروبات مُدرجة حسب آخر قائمة زوّدنا بها. أسعار الشحن عن طريق ID داخل هذه النسخة مبدئية وتحتاج مراجعة قبل استخدامها.
- جرّب طلبًا تجريبيًا بمبلغ غير مدفوع قبل إعلان الموقع للعملاء.
